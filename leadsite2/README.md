# LeadSite 2.0

## Visão geral
Um SaaS que permite a criação automática de sites de captura de leads, gerenciamento de leads em um CRM interno e automação de comunicação via WhatsApp e e‑mail.

- **Front‑end**: Next.js (React + TailwindCSS)
- **Back‑end**: API Serverless (Next.js API Routes)
- **Banco de dados**: Supabase (PostgreSQL + Auth)
- **Fila**: BullMQ + Upstash Redis
- **LLM para geração de site**: OpenAI GPT‑4o (ou outro modelo compatível)
- **WhatsApp**: Twilio Conversations
- **Pagamentos**: Stripe

Veja o `README.md` para instruções de instalação e deployment.
